# demoqa-ui-automation

UI test automation project for [DemoQA](https://demoqa.com) — a practice website for QA engineers.

## 🛠 Tech Stack

| Tool | Purpose |
|------|---------|
| Java 17 | Programming language |
| Selenium  | UI browser automation |
| TestNG | Test framework |
| Allure | Test reporting |
| Lombok | Boilerplate reduction |
| JavaFaker | Test data generation |
| AssertJ | Assertions |
| Maven | Build tool |

## 📋 Test Coverage

- Accordion
- Alert & Popups
- Auto Complete
- Buttons
- Frames
- Menu Navigation
- Practice Form
- Select Menu
- Text Box
- Web Tables
- Browser Windows
- Amazon Tests



### Smoke tests

mvn test -Dsuite=smoke_suite.xml

### Regression tests

mvn test -Dsuite=regress_suite.xml
